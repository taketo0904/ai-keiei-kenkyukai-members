### 本番の認証方式（2026-08-23 決定）

**Cloudflare Access ＋ Google OAuth** で実装します。合言葉方式は本番では使いません。

Googleの認証基盤を使うことで利用者側の安心感が得られること、そしてGoogle Workspaceと連携しておけば、退職者のアカウントがWorkspace側で停止・削除された時点で自動的にログインできなくなることが理由です。「この人が退職したので権限を消してください」という個別連絡を受けて対応する運用が不要になり、権限の削除漏れと、退職後もアカウントが残って情報を持ち出せてしまうリスクを同時に抑えられます。

Cloudflare Access は Google を IdP として設定でき、メールアドレス単位・グループ単位でのアクセス制御ができるため、管理者グループだけ管理画面に通す構成もそのまま組めます。

### ⚠️ 現状の権限分離はセキュリティではありません（実装前の暫定）

静的ホスティングのため、権限判定はすべてブラウザ側で行っています。**合言葉は両方ともJavaScriptに直書きで、ソースを見れば読めます。**管理タブを隠しているだけで、その気になれば会員アカウントからでも管理画面を開けます。

ただし実害は限定的です。管理画面でできるのはブラウザ上での編集とJSONの出力だけで、**サイトの中身を書き換えるにはリポジトリへのpush権限が別途必要**です。読まれて困るのは会員名簿の中身であり、そこはサイト全体の認証で守る話になります。

上の「本番の認証方式」に置き換えるまでの暫定です。

## 管理画面の使い方

「管理」タブ → 2つのタブがあります。

**動画の登録**：全プロダクトの事例が一覧で出るので、Vimeo URLを貼り付けます。貼ると右端に `OK` / `形式NG` が出ます。入力し終えたら「videos.json を出力」→「コピー」または「ダウンロード」。

**会員名簿の編集**：選択中のプロダクトの会員を編集します。得意分野はカンマ区切り。追加・削除もできます。「members.json を出力」で同様に取り出します。

出力したJSONでリポジトリの同名ファイルを差し替えて push すると、数分でサイトに反映されます。

| 画面 | 会議での決定 |
|---|---|
| ログインゲート | 一般公開せずクローズド運用 |
| オリエンテーション | 動画ジャンルとは別建て。ホームとメニューから導線 |
| ホーム | ビジョン → オリエン → 事例インタビュー → サービス紹介 → 事例動画 → 過去の研究会 → 壁打ち会 → 会員名簿 |
| 動画 | 分野から探す／事例をまとめて見る。Notionの事例プラットフォームの分野構成に対応 |
| 会員名簿 | 顔写真・エリア・入会年月・得意分野・施工範囲・手がけた工事・ひとこと・自由記述・メール。管理者は編集可 |
| 事例インタビュー | 動画＋インタビュー記事。入会後の変化にフォーカス。ガイダンス・営業での使いどころも併記 |
| 無料壁打ち会 | 「無料AI顧問」から改称、プッシュ型・定例化 |
| サービス紹介 | 斎藤さん要望のアップセル用ページ |

## 動画の入れ方（Vimeo）

`index.html` は触りません。**`videos.json` に1行足して push するだけ**です。

1. Vimeo に動画をアップする
2. その動画のURLをコピーする（管理画面のURLでもOK）
3. `videos.json` を開き、事例IDをキーにしてURLを書く

```json
{
  "e1": "https://vimeo.com/123456789",
  "s3": "https://vimeo.com/987654321/a1b2c3d4e5",
  "m1": { "url": "https://vimeo.com/555555555", "min": 12 }
}
```

4. commit して push。数分で反映されます

### 受け付けるURLの形

| 形 | 例 |
|---|---|
| 通常 | `https://vimeo.com/123456789` |
| 限定公開（ハッシュ付き） | `https://vimeo.com/123456789/a1b2c3d4e5` |
| 管理画面のURL | `https://vimeo.com/manage/videos/123456789` |
| プレーヤーURL | `https://player.vimeo.com/video/123456789?h=a1b2c3d4e5` |
| 数字IDだけ | `123456789` |

`{ "url": "...", "min": 12 }` の形にすると、一覧に尺（12分）も出ます。

### Vimeo側の公開設定

サイトは会員限定なので、Vimeo側も「このサイトでのみ埋め込みを許可」にしておくのが安全です。

- Vimeo の動画設定 → プライバシー → **「動画の表示」を「非公開」または「限定公開（リンクを知っている人のみ）」**
- **「埋め込み」を「特定のドメインのみ」** にし、`taketo0904.github.io` を許可リストに追加
- ドメイン制限を使うには Vimeo の Plus 以上のプランが必要です。無料プランの場合は「限定公開＋ハッシュ付きURL」で運用してください

ドメイン制限をかけると、動画URLが外に漏れてもこのサイト以外では再生できなくなります。会員サイトの認証が仮実装のうちは、これが実質的な保護になります。
