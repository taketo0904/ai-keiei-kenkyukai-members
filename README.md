### 動画の持ち方

コース（順番に受講するカリキュラム）ではなく、**ジャンル → グループ → 動画**の3階層で分類している。

- ジャンル：オリエンテーション／研究会アーカイブ／AI基礎／営業・見積／現場・施工／設計・プラン／集客・広報／経営・管理
- グループ：ジャンル内のまとまり。研究会アーカイブでは「VOL.04（2026.08）」のように開催回がグループになる
- 動画：タイトル・尺・登壇者を持つ。`nw:1` を立てると新着タブに出る

事例プラットフォーム（動画本体）は電通のeラーニングサービスへ移管するため、このサイトには含めていない。

## 杉山さんに相談したい点（未実装）

**現在のログインは本番で使えません。** 合言葉をJSに直書きしたデモ用ゲートで、ソースを見れば誰でも通過できます。GitHub Pages は静的ホスティングなのでサーバー側で認証を持てず、次のいずれかの判断が必要です。

1. Cloudflare Access など、ホスティングの手前で認証をかける（GitHub Pages のままでいける）
2. Cloudflare Pages / Netlify に移し、Functions でセッションを持つ
3. Firebase Authentication などのIDaaSをフロントから使う（Pages のままでいける）

会員の入退会にあわせてアクセス権を足し引きする運用まで含めて決めたい。Notion の「アクセスリクエスト→承認」がシームレスでなかったのが刷新のきっかけなので、ここは自動化したい。

## 差し替えが必要なプレースホルダ

- 動画のURL（現在はクリックで案内トーストが出るだけ）
- オリエンテーション動画の埋め込み枠
- 事前アンケートのURL
- TimeRex の予約URL
- 次回研究会の日程・会場
- サンプルデータ（`index.html` 内の `GENRES` / `EVENTS` / `MEMBERS` / `CASES` / `SERVICES` 配列）

## 会員名簿の掲載について

写真・得意分野・連絡先の掲載可否は会員ごとに確認が必要。掲載範囲を本人が選べる旨を画面上に明記済み。実データを入れる前に確認フローを固めること。
